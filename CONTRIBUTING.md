# Contributing

1. Create a focused branch.
2. Keep calculations deterministic and source-aware.
3. Add or update tests for behavioral changes.
4. Run `npm run check` and `npm audit --omit=dev`.
5. Explain changes to the data contract or scoring method in the pull request.

Do not add real company data to examples unless its public-release rights are clear. Prefer compact synthetic fixtures that expose edge cases.
